# DJ Genie Studio Releases

Public **installer downloads only**. No application source code is published here.

## macOS install (unnotarized free builds)

1. Download the DMG for your Mac.
2. Open the DMG and drag the app to Applications.
3. Open the app. If macOS blocks it:
   - Click **Done** on the warning (or close it)
   - Open **System Settings → Privacy & Security**
   - Scroll to the message about DJ Genie and click **Open Anyway**
   - Confirm **Open** when prompted
   - Or Control-click the app → **Open** → **Open**
